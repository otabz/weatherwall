# SkyFlow Live Weather

A completely standalone Android live-wallpaper app with its own settings,
weather, location and animation code. It does not contain or download
WeatherMaster code.

## Location settings

The settings screen supports three location modes:

- **Search and choose a city** — search by city name or postcode and choose
  from matching city, region and country results.
- **Use current device location** — requests Android location permission and
  uses the phone's current coordinates.
- **Advanced manual coordinates** — accepts decimal latitude and longitude.

When a city or location is selected, SkyFlow saves its name and coordinates,
invalidates the old weather cache, downloads the new current weather and
updates an already-active wallpaper. The wallpaper service listens for the
saved weather change, cross-fades to the new scene and redraws without
requiring the wallpaper to be re-applied.

## Original weather scenes

The wallpaper uses original Android Canvas drawing code for:

- clear day and clear night skies
- sun, moon and stars
- moving clouds
- drizzle and rain
- snow
- fog
- thunderstorms and lightning
- day/night colours
- optional temperature, weather condition and selected city text

Current conditions are obtained from Open-Meteo and refreshed every 30 minutes
while the wallpaper is active. The last successful response is cached only for
the currently selected location.

## Privacy

The app contains no analytics, advertisements or account system.

- City searches send the entered search text to the Open-Meteo geocoding API.
- Weather refreshes send the selected latitude and longitude to Open-Meteo.
- Device location stays in the app except for the coordinates required to
  request weather.

Auckland, New Zealand is the initial default until another location is chosen.

## Build with GitHub Actions

1. Upload the contents of this project to a GitHub repository.
2. Ensure this file exists at `.github/workflows/build-apk.yml`.
3. Open the repository **Actions** tab.
4. Select **Build SkyFlow Live Weather APK**.
5. Choose **Run workflow**.
6. After the run succeeds, download **SkyFlow-Live-Weather-APK**.

The artifact contains a debug-signed APK that can be installed for testing.

## Build locally

Requirements:

- JDK 17
- Android SDK platform 36
- Android build tools 35.0.0 or later

Run:

```bash
chmod +x gradlew
./gradlew clean testDebugUnitTest assembleDebug
```

The APK is generated at:

```text
app/build/outputs/apk/debug/app-debug.apk
```
